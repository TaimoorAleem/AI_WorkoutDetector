## Setup and how it lines up with the classical pipeline

- Input: cleaned CSF-1 bins (200 ms), windows of W = 20 bins (4 s), stride 1, built within each set only; the label is the set label. Channels: 6 raw axes + `acc_r`, `gyr_r` (computed after augmentation) = 8, standardised with mean/std of the training participants' bins.
- Alignment: the classical models predict one row per 200 ms bin. A CNN window predicts its **last** bin, so the first W-1 = 19 bins (3.8 s) of every set have no prediction. Window-level metrics are therefore over `bins - sets * (W-1)` rows, a subset of the classical rows (the classical numbers are quoted from `current-baseline.md` and were not recomputed on that subset). Set-level accuracy is the same majority vote.
- Model: 3 x (Conv1d k5 -> BatchNorm -> ReLU) with 32/64/64 channels, max-pool after the first two, global average pooling, dropout 0.3, linear. Params: 32870.
- Training: AdamW lr 0.001, class-weighted cross-entropy (training fold), batch 128, up to 40 epochs, early stopping (patience 8) on macro-F1 of one held-out *training* participant (never the sole holder of a class in the training pool, then most classes, then most windows; never the test participant).
- Augmentation (D-018 distribution): per window, a fresh random proper rotation (axis uniform on the sphere, angle U[0, 30] deg) on both the acc and gyro triples before magnitudes; training windows only.
